<h1 align="center">📝 Blogify – Modern Laravel Blog Platform</h1>

<p align="center">
  <a href="https://blogify-production-823a.up.railway.app" target="_blank">
    🚀 Live Demo
  </a>
</p>

<p>
  Blogify adalah platform blog modern berbasis <strong>Laravel</strong> yang dirancang untuk memudahkan pengelolaan konten, pengguna, dan manajemen posting secara efisien. Proyek ini mendukung sistem autentikasi, peran (role-based access), manajemen user, serta fitur CRUD untuk posting.
</p>

<hr>

<h2>Fitur Utama</h2>
<ul>
  <li>🔐 <strong>Autentikasi & Role Management</strong></li>
  <li>📝 <strong>CRUD Post</strong> dengan editor yang nyaman</li>
  <li>👤 <strong>Manajemen User Admin</strong> (buat, edit, hapus)</li>
  <li>📸 <strong>Upload dan hapus foto profil</strong> menggunakan Cloudinary</li>
  <li>📱 <strong>Responsive Layout</strong></li>
</ul>

<hr>

<h2>Teknologi yang Digunakan</h2>
<ul>
  <li>Laravel 11</li>
  <li>MySQL</li>
  <li>TailwindCSS</li>
  <li>Cloudinary (image storage)</li>
</ul>

<hr>

<h2>Instalasi</h2>

<pre>
<code>
git clone https://github.com/username/repo-blogify.git
cd repo-blogify

composer install
npm install
npm run build

cp .env.example .env
php artisan key:generate

php artisan migrate --seed
php artisan serve
</code>
</pre>
